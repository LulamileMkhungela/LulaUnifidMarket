# Fonts

Both typefaces are self-hosted (no third-party font CDN, so no extra DNS
lookups, no tracking and they work offline once the service worker has them).

| File | Family | Licence | Source |
| --- | --- | --- | --- |

| `bricolage-latin.woff2` | Bricolage Grotesque (variable, 200–800), Latin subset | SIL Open Font License 1.1 | Mathieu Triay — github.com/ateliertriay/bricolage, via the `@fontsource-variable/bricolage-grotesque` package |

The SIL Open Font License permits bundling and redistribution with software;
the full licence texts ship alongside the files (`OFL-*.txt`).
